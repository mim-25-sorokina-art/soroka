⚙️ Технічна документація проєкту

Використаний стек технологій:

  • HTML5 & CSS3: Структура сайту та адаптивний дизайн для мобільних пристроїв.
  • A-Frame (v1.2.0): Веб-фреймворк для створення 3D-графіки у браузері.
  • AR.js: Бібліотека для оптичного трекінгу маркерів за допомогою веб-камери.
  • JavaScript (ES6): Логіка взаємодії, відстеження подій кліку та запуск анімації розгортки куба.

Проєкт хоститься на серверах GitHub Pages і працює без серверної частини (Client-side app).
